Why RankLens

把「查等级」变成打开页面就有的信息

不用记住榜单、不用来回切换网页——论文旁边的等级信息，RankLens 已经帮你放好。

A

CCF 推荐等级

对齐 CCF 2026 最新目录，A / B / C 一眼识别，计算机领域的会议与期刊全覆盖。

1

中科院分区

1–4 区、Top、大类与位次一目了然；全学科 21,771 种期刊名称索引，不止计算机领域。

新

新锐期刊分区

原中科院分区团队出品的新锐分区表，补充分区、Top 与数据库覆盖，为选刊提供更多视角。

EI

EI 可追溯状态

仅基于本地生成的 Elsevier Compendex 官方来源表快照显示，绝不拿其他指标“推测”收录。

◎

智能匹配与回退

优先 dblp、ISSN 与完整 venue 名称；识别不到时再由 OpenAlex / Crossref 恢复元数据。

◈

隐私优先

大部分匹配在本地完成，不上传浏览历史，无分析服务器，Manifest V3 下声明最少权限。

How it works

三步开始使用

从安装到看见第一个等级徽标，只需要几分钟。

01

安装 RankLens

下载 Release 或克隆源码，在 Chrome / Edge 的开发者模式下加载扩展目录。

02

打开任意学术网页

dblp、Google Scholar、检索库、出版社与会议论文集页面——都支持。

03

等级自动出现

CCF、中科院分区、新锐分区与 EI 徽标，直接显示在论文标题旁边。
